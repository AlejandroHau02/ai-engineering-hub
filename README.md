# AI Engineering Hub

Repositorio **personal y público** de un entorno reutilizable para Claude Code y Codex.

**Estado:** experimental, v0.1 en construcción.

El objetivo es convertir asistentes de código en colaboradores con criterio de ingeniería, skills especializadas, validación basada en evidencia y supervisión de cambios de alto impacto.

- No contiene datos, código ni configuraciones privadas de proyectos de terceros.
- Las skills externas no se instalan ni ejecutan automáticamente.
- La configuración global requiere una acción explícita del usuario.

Las mejoras iniciales se desarrollarán mediante pull requests.

> Proyecto independiente; sin afiliación a un empleador o proveedor de modelos.
